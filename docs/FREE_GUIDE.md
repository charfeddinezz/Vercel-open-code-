# الدليل المجاني بالكامل — 0$ من البداية للنهاية

> لا بطاقة ائتمان في أي خطوة. إن طلب منك أي موقع بطاقة، فأنت في المكان الخاطئ.

## الحزمة المجانية

| الخدمة | دورها | الحد المجاني |
|---|---|---|
| Vercel Hobby | الموقع + Sandbox | جلسات حتى 45 دقيقة، ويكفي للاستخدام الشخصي اليومي |
| OpenRouter `:free` | نماذج الذكاء الاصطناعي | نماذج قوية مجانية بحدود يومية — الموقع يحظر المدفوع تلقائياً |
| GitHub Free | حفظ مشاريعك | مستودعات خاصة مجانية |
| OpenCode | وكيل البرمجة | مفتوح المصدر |

## الإعداد في 3 خطوات (من الهاتف أيضاً)

1. **المفتاح**: افتح [openrouter.ai/keys](https://openrouter.ai/keys) ← سجّل بـ Google ← Create Key ← انسخه.
2. **النشر**: من صفحة `/connect` في الموقع اضغط "انشر على Vercel بضغطة واحدة" ← الصق المفتاح عندما يطلبه ← Deploy.
3. **الهاتف**: امسح QR في صفحة `/connect` بكاميرا هاتفك ← ثبّت التطبيق من زر "تثبيت" ← انتهى.

## كيف يحميك الموقع من أي تكلفة؟

- `FREE_MODE` مفعّل افتراضياً: أي نموذج لا ينتهي بـ `:free` **يُرفض على الخادم** برسالة توضيحية (`PAID_MODEL_BLOCKED`).
- منتقي النماذج يعرض المجانية فقط افتراضياً.
- إن ازدحم نموذج مجاني، سلسلة احتياطية جاهزة في `src/lib/free.ts` (Qwen ← Llama ← DeepSeek ← Gemini ← Mistral).
- التكلفة المعروضة في تبويب المقاييس للنماذج المجانية = **0$ دائماً**.

## حدود الواقع (بشفافية)

- النماذج المجانية لها حدود طلبات يومية من OpenRouter نفسه — عند بلوغها بدّل النموذج من منتقي النماذج.
- جلسة Hobby تنتهي بعد 45 دقيقة كحد أقصى — الموقع يحفظ Snapshot + GitHub قبل الانتهاء، والاستعادة باسم المشروع نفسه.
- للاستخدام الجماعي الثقيل قد تحتاج خطة أعلى في Vercel — لكن للاستخدام الشخصي، المجاني يكفي ويزيد.

## تعطيل الوضع المجاني (للمتقدمين فقط)

على الخادم: `FREE_MODE=false` أو `ALLOW_PAID_MODELS=true` في متغيرات بيئة Vercel. عندها تتحمل أنت أي تكلفة نماذج مدفوعة تختارها.
